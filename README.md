# powrotdoex.pl

Landing page sprzedażowy e-booka „Powrót do ex”.

## Struktura

- `index.html` — struktura strony i treść
- `css/style.css` — cały wygląd, responsywność i animacje CSS
- `js/main.js` — interakcje JavaScript
- `assets/okladka-ebooka.png` — rzeczywista okładka e-booka

## Uruchomienie

Najprościej otworzyć `index.html` w przeglądarce.

W VS Code można też użyć rozszerzenia Live Server.

## Kolejny etap

Przycisk zakupu jest obecnie placeholderem. W kolejnym etapie można podłączyć operatora płatności i automatyczne dostarczanie PDF po udanej transakcji.
